# 📘 백준 알고리즘 문제 풀이 모음

## 🔄 BOJ 1931 - 회의실 배정

### 📌 문제 정보

- **문제 번호**: [1931번 - 회의실 배정](https://www.acmicpc.net/problem/1931)
- **난이도**: 실버 1
- **분류**: 그리디 알고리즘, 정렬

---

### 📄 문제 설명

한 개의 회의실이 있는데 이를 사용하고자 하는 N개의 회의에 대하여 회의실 사용표를 만들려고 한다.  
각 회의 i에 대해 시작시간과 끝나는 시간이 주어져 있으며, **회의가 겹치지 않게** 하면서 회의실을 사용할 수 있는 회의의 최대 개수를 찾아야 한다.

- 회의는 한번 시작하면 중간에 중단될 수 없다.
- 한 회의가 끝나는 것과 동시에 다음 회의가 시작될 수 있다.
- 회의의 시작 시간과 끝나는 시간이 같을 수도 있다. (시작하자마자 끝나는 것으로 간주)

---

### ✅ 조건

- 입력:
    - 첫째 줄: 회의 수 N (1 ≤ N ≤ 100,000)
    - 둘째 줄부터 N개의 줄: 각 회의의 시작시간과 끝나는 시간 (0 ≤ 시간 ≤ 2³¹-1)
- 출력:
    - 사용할 수 있는 회의의 최대 개수

---

### 💡 풀이 아이디어

- **끝나는 시간**을 기준으로 회의를 정렬한다.
- 끝나는 시간이 같을 경우 **시작 시간**을 기준으로 정렬한다.
- 가장 빨리 끝나는 회의를 먼저 선택하고, 겹치지 않는 다음 회의를 선택해나간다.

---

### ✨ 예시

| 입력 | 출력 |
| :--- | :--- |
| 11<br>1 4<br>3 5<br>0 6<br>5 7<br>3 8<br>5 9<br>6 10<br>8 11<br>8 12<br>2 13<br>12 14 | 4 |

- 선택한 회의: (1,4), (5,7), (8,11), (12,14)

## 💻 Java 코드

```java
package baekjun_daily;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.stream.Collectors;

public class _1931 {
    public static void main(String[] args) throws IOException {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        int cnt = Integer.parseInt(bf.readLine());
        List<Time> timeList = new ArrayList<>();

        for (int i = 0; i < cnt; i++) {
            String[] times = bf.readLine().split(" ");
            int start = Integer.parseInt(times[0]);
            int end = Integer.parseInt(times[1]);
            Time time = new Time(start, end);
            timeList.add(time);
        }

        // greedy 탐색
        // 마지막 시간을 기준으로 가장 적은 숫자로 정렬을 해야 최적의 경로를 찾을 수 있다.
        timeList.sort((a, b) -> {
            return a.getE() == b.getE() ? Integer.compare(a.getS(), b.getS()) : Integer.compare(a.getE(), b.getE());
        });

        timeList.forEach(i -> System.out.println(i.getS() + ":" + i.getE()));

        ArrayList<Time> greedyList = new ArrayList<>();
        int lastTime = 0;
        for (Time time : timeList) {
            int endTime = time.getE();
            int startTime = time.getS();

            if (lastTime <= startTime) {
                greedyList.add(time);
                lastTime = endTime;
            }
        }

        greedyList.forEach(i -> System.out.print("[" + i.getS() + ":" + i.getE() + "] "));
        System.out.println(greedyList.size());
    }

    static class Time {
        private int s;
        private int e;

        Time(int s, int e) {
            this.s = s;
            this.e = e;
        }

        int getS() {
            return s;
        }

        int getE() {
            return e;
        }
    }
}

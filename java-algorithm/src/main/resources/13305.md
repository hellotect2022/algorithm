# 주유소

- **문제 번호**: [13305번 - 주유소](https://www.acmicpc.net/problem/13305)
- **난이도**: 실버 3
- **분류**: 그리디 알고리즘, 수학

---

## 📄 문제 설명

어떤 나라에 N개의 도시가 있다. 이 도시들은 일직선 도로 위에 있다.  
처음 출발할 때 자동차에는 기름이 없고, 도로를 따라 이동하려면 1km당 1리터의 기름을 사용한다.

각 도시에는 하나의 주유소가 있으며, 주유소마다 리터당 가격이 다를 수 있다.  
출발 도시부터 도착 도시까지 이동하는 데 드는 **최소 비용**을 구하자.

---

## ✅ 입력

- 첫째 줄: 도시의 개수 N (2 ≤ N ≤ 100,000)
- 둘째 줄: 인접한 두 도시를 연결하는 도로의 길이 N-1개 (1 ≤ 거리 ≤ 1,000,000,000)
- 셋째 줄: 각 도시의 리터당 주유 가격 N개 (1 ≤ 가격 ≤ 1,000,000,000)

---

## ✅ 출력

- 최소 비용을 출력한다.

---

## 💡 예제

| 입력   | 출력 |
|--------|------|
| 4<br>2 3 1<br>5 2 4 1 | 18 |
| 4<br>3 3 4<br>1 1 1 1 | 10 |

## 💻 Java 코드

```java
package baekjun_daily;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class _13305 {
    public static void main(String[] args) throws IOException {
        // 58점짜리 답
        //result_58();

        // 100점짜리 답
        result_100();
    }

    public static void result_100() throws IOException {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        int cnt = Integer.parseInt(bf.readLine()) - 1;
        String[] distanceLine = bf.readLine().split(" ");
        String[] priceLine = bf.readLine().split(" ");

        long lastPrice = Long.parseLong(priceLine[0]);
        long sum = lastPrice * Long.parseLong(distanceLine[0]);

        for (int i = 1; i < cnt; i++) {
            long price = Long.parseLong(priceLine[i]);
            long distance = Long.parseLong(distanceLine[i]);

            if (lastPrice > price) {
                sum += price * distance;
                lastPrice = price;
            } else {
                sum += lastPrice * distance;
            }
        }

        System.out.println(sum);
    }

    public static void result_58() throws IOException {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        int cnt = Integer.parseInt(bf.readLine()) - 1;
        String[] distanceLine = bf.readLine().split(" ");
        String[] priceLine = bf.readLine().split(" ");

        long lastPrice = Long.parseLong(priceLine[0]);
        long sum = lastPrice * Long.parseLong(distanceLine[0]);

        for (int i = 1; i < cnt; i++) {
            long price = Integer.parseInt(priceLine[i]);
            long distance = Integer.parseInt(distanceLine[i]);

            if (lastPrice > price) {
                sum += price * distance;
                lastPrice = price;
            } else {
                sum += lastPrice * distance;
            }
        }

        System.out.println(sum);
    }
}
```
# 주유소 - 풀이 요약 및 팁

## 🚀 문제 풀이 요약

- 가장 왼쪽 도시부터 출발하여 이동한다.
- 현재까지 가장 싼 주유소에서 계속 기름을 넣는 전략을 사용한다.
- 매 도로 길이만큼 필요한 연료를 계산해서, 현재 가장 싼 가격으로 구매한다.
- 가격이 더 싼 주유소를 만나면, 거기서부터 새 가격을 적용한다.

---

## 🧠 문제 풀이 팁

- **핵심**: "이전까지 본 주유소 중 가장 싼 곳"을 기준으로 계산해야 한다.
- **그리디 알고리즘**: 항상 지금까지 가장 저렴한 가격을 유지해야 최적해를 구할 수 있다.
- **자료형 주의**: 거리, 가격 모두 1,000,000,000(10억)까지 가능하므로, 곱셈 결과는 `long`으로 처리해야 한다.
- 매번 새로운 도시에서 가격 비교를 하고, 적절히 `lastPrice`를 갱신해나간다.
- 최종적으로 모든 거리들을 이동할 때의 최소 비용을 합산한다.

---

## ⚡ 주의사항

- **자료형 문제**: `int`로 곱셈하면 오버플로우가 발생할 수 있다.  
  ➔ 반드시 `long` 타입으로 파싱(`Long.parseLong`)하고 연산해야 한다.
- **초기화 실수**: 출발 도시의 가격(`price[0]`)으로 초기 주유 가격을 세팅해야 한다.
- **거리 입력/가격 입력 순서**를 정확히 맞춰서 처리해야 한다.
- **루프 인덱스 관리 주의**: 도시 수 `N`이 주어지면 도로는 `N-1`개다.

# 잃어버린 괄호

- **문제 번호**: [1541번 - 잃어버린 괄호](https://www.acmicpc.net/problem/1541)
- **난이도**: 실버 2
- **분류**: 그리디 알고리즘, 문자열, 수학

---

## 📄 문제 설명

세준이는 양수와 `+`, `-`, 그리고 괄호를 가지고 식을 만들었습니다.  
하지만 나중에 괄호를 모두 지워버렸습니다.

세준이는 괄호를 적절히 쳐서 이 식의 값을 **최소로 만들려고** 합니다.  
**괄호를 적절히 쳐서 식의 값을 최소로 만드는 프로그램을 작성하세요.**

---

## ✅ 입력

- 첫째 줄에 식이 주어집니다.
- 식은 `0`~`9`, `+`, `-`만으로 이루어져 있습니다.
- 가장 처음과 마지막 문자는 숫자입니다.
- 연속해서 두 개 이상의 연산자가 나타나지 않습니다.
- 연속된 숫자는 최대 5자리입니다.
- 식의 길이는 50보다 작거나 같습니다.

---

## ✅ 출력

- 괄호를 적절히 쳐서 만든 식의 **최솟값**을 출력합니다.

---

## 💡 예제

| 입력            | 출력  |
|-----------------|-------|
| 55-50+40        | -35   |
| 10+20+30+40     | 100   |
| 00009-00009     | 0     |

---

## 💻 Java 코드

```java
package baekjun_daily;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.ArrayList;
import java.util.Arrays;

public class _1541 {
    public static void main(String[] args) throws IOException {
        ArrayList<String> tokenList = new ArrayList<>();
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        // -를 기준으로 문자열을 분할합니다.
        // 첫 번째 파트는 그냥 덧셈합니다.
        // 이후 파트들은 모두 내부의 +를 계산한 후 결과값에서 뺍니다.
        String line = bf.readLine();
        String[] valueList = line.split("[-]");
        int sum = Arrays.stream(valueList[0].split("[+]")).mapToInt(Integer::parseInt).sum();

        for (int i = 1; i < valueList.length; i++) {
            String[] value = valueList[i].split("[+]");
            for (String val : value) {
                sum -= Integer.parseInt(val);
            }
        }

        System.out.println(sum);
    }
}
```

# 문제풀이 팁 - 잃어버린 괄호 (BOJ 1541)

## 🧠 핵심 아이디어

- 수식을 입력받고, `-`를 기준으로 나누어 생각합니다.
- **처음으로 등장하는 `-` 이후**의 모든 수를 괄호로 묶어 한 번에 빼야 최솟값이 됩니다.
- 식을 `-`로 split하고, 각각 내부에서 `+`를 먼저 계산합니다.

---

## 🛠️ 풀이 방법

1. 식을 `-` 기호로 split 합니다.
2. 첫 번째 파트는 `+` 기준으로 나눠서 전부 더합니다.
3. 두 번째 파트부터는 각각 `+`를 모두 계산한 후, 합산값을 전체 합계에서 빼줍니다.

---

## ⚡ 주의사항

- `+` 연산자는 split 시에 반드시 정규식 형태로 `"[+]"`를 사용해야 합니다.
- 숫자는 0으로 시작할 수 있지만, `Integer.parseInt`를 사용하면 자동으로 처리됩니다.
- `-` 뒤의 `+`를 제대로 괄호로 묶지 않으면 최솟값이 나오지 않습니다.

---

## ⏱️ 시간복잡도

- 문자열 길이 `N`에 대해 한 번 순회하므로 시간복잡도는 **O(N)** 입니다.
- 입력 크기 제한(50자 이내) 때문에 시간 초과 걱정은 없습니다.
